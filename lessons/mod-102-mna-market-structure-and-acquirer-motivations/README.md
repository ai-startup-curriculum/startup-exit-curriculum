# mod-102 — M&A Market Structure & Acquirer Motivations

**Estimated effort:** 22 hours
**Stage:** GROWTH / MATURE (the frame installs earlier; the sell-side execution disciplines here are exercised when a transaction is proximate — within 6–24 months of a plausible sale)
**Seat:** founder-CEO, CFO, GC, SVP-Corp-Dev, board-observer, investment-banking VP / Director

This module is where the sell-side apparatus becomes an operating skill. mod-101 framed acquisition as one of five endgame outcomes and installed the rolling buyer map as a *live-option* discipline. mod-102 takes that map and pushes it to the depth a CFO / SVP-Corp-Dev / lead banker would recognise: strategic-vs-financial acquirer typology at the level where each type prices, integrates, and negotiates differently; the aqui-hire / tuck-in / platform / transformative-strategic classification and what each shape means for consideration mix and post-close terms; the banker-engagement decision that sits under every serious sell-side; the teaser / CIM / management-presentation document set that carries the narrative into the market; and the pre-marketing choreography that seeds a competitive process without triggering fiduciary-out obligations or telegraphing capitulation.

The module owns the *market-structure and pre-marketing* layer of sell-side M&A. It does not re-teach valuation methodology ([`startup-finance-fundraising-curriculum`](https://github.com/ai-startup-curriculum/startup-finance-fundraising-curriculum) mod-106 owns Berkus, VC-method, revenue multiples, and LBO math), it does not re-teach the data room or diligence workstreams (mod-105 in this track owns those), and it does not re-teach deal-structure or definitive-agreement authoring (mod-103 and mod-104 own those). It sits between the endgame frame and the transaction itself: this is what a founder-CEO and CFO do in the 6–24 months before a live sell-side.

## Learning objectives

By the end of this module you should be able to:

- Distinguish strategic and financial acquirer typologies at the depth where each type's pricing model, integration approach, and negotiating behaviour are explicit rather than folkloric.
- Classify a specific transaction as an aqui-hire, tuck-in, platform, or transformative-strategic deal and derive what that classification implies for consideration mix, employee-retention terms, integration model, and post-close governance.
- Author a buyer map at CFO / SVP-Corp-Dev depth — the six-dimension scoring extended with process-behaviour, integration-appetite, and cultural-fit sub-diligence, plus a quarterly board-review cadence.
- Make the investment-bank engagement decision — sole vs. dual mandate, tier-1 vs. sector-boutique vs. Big-Four M&A vs. no-banker sell-side — and negotiate the retainer + success-fee + expense economics against the incentive structure they create.
- Author the pre-marketing document set (teaser, CIM, management presentation) with a consistent narrative across all three artefacts and with the data room being built in parallel under mod-105.
- Choreograph pre-marketing conversations that surface acquirer interest without triggering fiduciary-out or no-shop obligations, and time a formal sell-side so it does not cannibalise an ongoing-company fundraising process.

## Ownership boundary

This module owns the market-structure and pre-marketing layer of sell-side M&A. It does *not* re-teach:

- **Valuation methodology** (Berkus, VC method, revenue multiples, LBO math, DCF, precedent-transaction and comparable-company screens at Rosenbaum-Pearl depth) — `startup-finance-fundraising-curriculum` mod-106 owns those. This module uses valuation as an *input* to buyer conversations and as the framing for the CIM's financial section; it does not re-teach how the numbers are built.
- **The rolling buyer map as an ongoing-company discipline** — mod-101 in this track owns the "keep the map warm for years" frame. This module extends the map from the endgame-framing depth to the sell-side-execution depth used when a process is proximate.
- **Deal structure and consideration design** (asset vs. stock vs. reverse-triangular, earn-outs, escrow, tax under IRC §368 / §338(h)(10) / §280G / §409A / §1202, HSR / CFIUS clearance) — mod-103 in this track owns those. When this module refers to consideration mix, it is at the choose-the-shape level, not the draft-the-mechanics level.
- **LOI and definitive-agreement authoring** — mod-104 owns those.
- **Sell-side data-room construction and diligence-workstream response** — mod-105 owns those. This module coordinates *with* the data-room build so the CIM narrative and the data-room contents are consistent; it does not teach how to construct the room.
- **Transaction-governance and Delaware fiduciary-duty analysis at deal-scale** — mod-109 owns Revlon, Corwin, MFW, special-committee construction, fairness-opinion procurement, and Rural Metro banker-conflict analysis. This module surfaces the pre-marketing choices that later become fiduciary-duty questions; it does not adjudicate them.

What this module *adds* on top: the acquirer-typology depth that makes buyer conversations concrete, the transaction-type classification that makes an LOI evaluable before it is drafted, the banker-engagement decision that shapes every subsequent choice, the pre-marketing document set as an authored artefact rather than a template dump, and the pre-marketing choreography that turns the buyer map from a warm relationship set into a live competitive process.

## How to work through this module

Carry the same company you profiled in mod-101 through this module. The whole point is that the buyer map you built in mod-101 exercise-02 gets extended into a sell-side-grade map in mod-102 exercise-03, and the endgame-optionality memo you drafted in mod-101 exercise-05 becomes the source narrative for the CIM you draft in mod-102 exercise-05.

Read a chapter, then do the matching exercise while the frame is fresh. Chapters 1–2 install the typology vocabulary that lets you name what kind of buyer and what kind of deal you are actually talking about. Chapter 3 extends the buyer map. Chapter 4 decides how the process gets executed. Chapters 5–6 build the artefacts and choreograph the market conversation. The project pack (`project-101-sell-side-m-and-a-execution-pack`) then assembles the module's outputs into a coherent sell-side execution kit.
